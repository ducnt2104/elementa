# ELEMENTA — SPECIALIST GRAPHICS & GAMEPLAY SKILLS MANIFEST

This manifest documents the specialized Agent Skills operationalized for the **ELEMENTA — Extreme Visual Overhaul** campaign.

| Skill Identifier | Scope & Capability | Target System |
| :--- | :--- | :--- |
| `elementa-art-direction` | Art direction bible, chemical color semantics, silhouette standards, visual hierarchy | Battlefield, Heroes, UI Tokens |
| `elementa-moba-environment-art` | 2D/2.5D MOBA arena geography, offscreen terrain cache, water caustics, volumetric foliage | `periodicRiftMap.ts`, `mobaRenderer.ts` |
| `elementa-game-vfx` | Layered combat VFX, particle object pooling, projectile trails, ability telegraph decals | `mobaRenderer.ts`, `mobaEngine.ts` |

| `elementa-rendering-performance` | 60 FPS frame budgeting, viewport culling, zero-alloc loop, adaptive quality tiers | `mobaRenderer.ts`, Settings |
